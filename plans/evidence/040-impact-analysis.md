## Four laws across the shipped surfaces

| Surface | Laws and checked boundary |
|---|---|
| Compound local writes and `fromLocal` | Laws 2 and 4. The renderer uses declared local keys, strips local directives before dispatch and completes values from current local state. The host rejects posted directives and checks the completed value against the offered state or action schema. [037 law cases](037-impact-analysis.md#3-the-four-laws). |
| Array carries and `focus` | Laws 2 and 4. Arrays are bounded scalar carries and rechecked by the host. The focus id must resolve to an ungated node in the accepted tree and moves focus only within the current surface and its portal. Focus raises no host intent. [037 law cases](037-impact-analysis.md#3-the-four-laws). |
| `putStateIf` and `pending` | Laws 2 and 4. The host authorizes and validates before conditional writes, then re-reads and revalidates after a conflict within the retry bound. A pending source exposes a declared status without host text or an attached value. [Store and host spec](../../docs/spec.md#77-the-host-pipeline), [038 law cases](038-impact-analysis.md#3-the-four-laws). |
| `motion` and windowing | Laws 2–4. A closed motion keyword and timing come from the design system. Exiting elements stay inert. Window bounds come through checked state and the rendered slice passes whole-tree limits. [038 law cases](038-impact-analysis.md#3-the-four-laws). |
| `/dom` | Laws 1–4. App implementations draw validated contexts with installed recipes. The adapter evaluates no widget source and uses shared completion, local-state isolation and invalid-arrival handling. [038 law cases](038-impact-analysis.md#3-the-four-laws). |
| Element-JSON bindings and digest | Laws 1–4. The closed, bounded expression evaluator works on validated data and caller-declared local state. The digest contains declarations and excludes design values, filesystem paths and capability metadata. [039 law cases](039-impact-analysis.md#3-the-four-laws). |
| `fromA2ui` and starter primitives | Laws 1–4. The converter emits inert element JSON, with action offers limited by the host mapping and manifest. SDK validation, authorization and dispatch remain host-controlled. Starter formatted text draws parsed tokens with URL checks and chart paint comes through recipe classes. [039 law cases](039-impact-analysis.md#3-the-four-laws). |
