# Security checklist

What Liveframe checks for you, and what your app must do itself. Work through it before you serve widgets you did not write. The [security model](security.md) explains each boundary. The [host guide](host.md#what-stays-yours) covers the duties that belong to the host pipeline.

Each row ends with a test that proves what the library checks, or the request that tracks the gap. Where a row names a request, the library does not check that concern today.

| Concern | The library checks | Your app must | Proof or request |
| --- | --- | --- | --- |
| Server-side confirmation of a `confirm` or `irreversible` action | `<Surface>` asks your `confirm` callback before it emits such an action, and drops the action if confirmation fails. It does this only when you pass `confirm`. `handleIntent` cannot tell whether the user confirmed. | Pass `confirm` to every surface. Enforce confirmation on the server, for example with a one-time token bound to the session, widget and action. | [`react-browser.test.tsx`](https://github.com/ashiqrniloy/liveframe/blob/main/src/__tests__/react-browser.test.tsx), `unconfirmed_action_never_reaches_on_intent_and_confirm_throw_raises_nothing`; not checked on the host: [LF-22](https://github.com/ashiqrniloy/liveframe/blob/main/plans/requests/synapta-0.4.0-requests.md#lf-22--bug--a-confirm-action-can-dispatch-unconfirmed-and-the-host-cannot-tell) |
| Idempotency and double submits | An intent from an older revision is refused. Nothing stops the same intent arriving twice for the current revision. | Make `dispatch` idempotent, or de-duplicate on your side. | [`host-intent.test.ts`](https://github.com/ashiqrniloy/liveframe/blob/main/src/__tests__/host-intent.test.ts), `stale_revision_refused`; not checked by the library: [LF-23](https://github.com/ashiqrniloy/liveframe/blob/main/plans/requests/synapta-0.4.0-requests.md#lf-23--feature--intent-identity-exactly-once-dispatch-and-an-idempotency-key) |
| Cross-site request forgery on the intent endpoint | Not checked by the library. It ships no transport, and `handleIntent` trusts the viewer you pass it. | Authenticate the endpoint that receives intents, and refuse cross-site requests (same-site cookies, an origin check or a CSRF token). | [LF-65](https://github.com/ashiqrniloy/liveframe/blob/main/plans/requests/synapta-0.4.0-requests.md#lf-65--docs--security-guide-corrections-and-an-adopter-responsibility-checklist) |
| Keying `Served` and action statuses per viewer session | Widget state is stored per placement and scope. A render is skipped only for the same surface, placement and scope. `Served` and action statuses are returned to you; the library keeps neither. | Choose a scope per viewer wherever state must not be shared. Keep each `Served` and its action statuses per viewer session, placement and scope, and drop them when the session ends. | [`host-render.test.ts`](https://github.com/ashiqrniloy/liveframe/blob/main/src/__tests__/host-render.test.ts), `no_skip_for_other_surface_or_scope`; not checked by the library: [LF-28](https://github.com/ashiqrniloy/liveframe/blob/main/plans/requests/synapta-0.4.0-requests.md#lf-28--feature--served-cannot-be-persisted-so-a-multi-replica-host-has-no-session) |
| A widget author's literal action arguments | `checkOffered` refuses an intent whose arguments differ from the ones the served tree offered. It does not know whether the viewer may use those values. | In `authorize`, check every argument against the viewer. A literal id written by the widget author is input, not a grant. | [`offered.test.ts`](https://github.com/ashiqrniloy/liveframe/blob/main/src/__tests__/offered.test.ts), `host_rejects_a_changed_literal_a_posted_extra_argument_and_a_posted_from_local_beside_from_local`; not checked by the library: [LF-65](https://github.com/ashiqrniloy/liveframe/blob/main/plans/requests/synapta-0.4.0-requests.md#lf-65--docs--security-guide-corrections-and-an-adopter-responsibility-checklist) |
| Image and link hosts | A prop that declares `url` refuses schemes outside its list. Hosts are not checked. | Decide which hosts images and links may reach, and enforce it with `img-src` and `connect-src` in your CSP. Declare `url` on every URL-valued prop. | [`url.test.ts`](https://github.com/ashiqrniloy/liveframe/blob/main/src/__tests__/url.test.ts), `url_rejects_disallowed_scheme_case_insensitive`; hosts not checked by the library: [LF-20](https://github.com/ashiqrniloy/liveframe/blob/main/plans/requests/synapta-0.4.0-requests.md#lf-20--bug-security--url-props-have-no-host-constraint) |
| Personal data in trees, patches and events | `HostEvent`s carry ids, kinds and reasons, never values, and text a widget throws reaches them as a fixed message. Trees and patches carry whatever the widget renders. | Treat trees and patches as the viewer's data: do not log them, and send them only to that viewer. | [`host-render.test.ts`](https://github.com/ashiqrniloy/liveframe/blob/main/src/__tests__/host-render.test.ts), `thrown_widget_text_never_reaches_a_host_event`; trees and patches not checked by the library: [LF-21](https://github.com/ashiqrniloy/liveframe/blob/main/plans/requests/synapta-0.4.0-requests.md#lf-21--bug-security--widget-thrown-text-reaches-host-errors-and-hostevents) |
| Error text and ids in logs | A runner that crosses a process boundary can still return typed errors with any message text. Node ids and pointers carry keys the author chose. | Treat error messages, node ids and pointers as untrusted text before they reach your logs. | [`runner.test.ts`](https://github.com/ashiqrniloy/liveframe/blob/main/packages/runner-quickjs/src/__tests__/runner.test.ts), `quickjs_thrown_text_is_not_returned`; not checked by the library: [LF-21](https://github.com/ashiqrniloy/liveframe/blob/main/plans/requests/synapta-0.4.0-requests.md#lf-21--bug-security--widget-thrown-text-reaches-host-errors-and-hostevents) |
| Runner isolation | `quickjsRunner()` isolates widget code from host globals, bounds its time, memory and stack, and the host re-validates every tree. `inProcessRunner()` and `workerRunner()` are not sandboxes. | Run code from authors you do not trust in `quickjsRunner()`, inside an OS sandbox for defence in depth. | [`runner.test.ts`](https://github.com/ashiqrniloy/liveframe/blob/main/packages/runner-quickjs/src/__tests__/runner.test.ts), `quickjs_no_host_globals`; [`conformance-runner.test.ts`](https://github.com/ashiqrniloy/liveframe/blob/main/src/__tests__/conformance-runner.test.ts), `isolation_cases_fail_for_in_process_runner` |
| Template budgets | Every render spends `limits.steps` and stops at `limits.nodes`. `templateRunner()` has no wall-clock timeout. | Keep the default limits unless a real widget needs more, and route template packages to `templateRunner()`. | [`corpus.test.ts`](https://github.com/ashiqrniloy/liveframe/blob/main/src/__tests__/corpus.test.ts), `hostile_template_set_is_bounded` |
| Package authorship and content pinning | `hash-mismatch` catches content that no longer matches its own `hash`. A package with a recomputed hash under the same `id@version` is accepted, and a placement cannot pin content. | Review and approve packages yourself, and control who can write your store. | [`security-guide.test.ts`](https://github.com/ashiqrniloy/liveframe/blob/main/src/__tests__/security-guide.test.ts), `hash_mismatch_detects_a_stale_hash_and_not_a_recomputed_one`; pinning not checked by the library: [LF-19](https://github.com/ashiqrniloy/liveframe/blob/main/plans/requests/synapta-0.4.0-requests.md#lf-19--bug-security--a-placement-cannot-pin-a-packages-content) |
| Store tenancy and durability | `loadPlacement()` validates every record it reads, and a corrupt record is a typed error. Stores do not encrypt, enforce tenancy, take transactions or survive crashes. | Separate tenants, encrypt and back up the store yourself. | [`store-load.test.ts`](https://github.com/ashiqrniloy/liveframe/blob/main/src/__tests__/store-load.test.ts), `changed_record_misses_cache_and_corrupt_record_still_fails`; tenancy not checked by the library: [LF-33](https://github.com/ashiqrniloy/liveframe/blob/main/plans/requests/synapta-0.4.0-requests.md#lf-33--feature--store-for-multi-tenant-database-hosts) |
| `authorize` as the app's policy | `handleIntent` calls `authorize` before any write or dispatch. A `false` or a throw refuses. | Write the policy: who may do what, for which arguments. | [`host-intent.test.ts`](https://github.com/ashiqrniloy/liveframe/blob/main/src/__tests__/host-intent.test.ts), `no_effect_before_check_offered_and_authorize`; [`host-intent.test.ts`](https://github.com/ashiqrniloy/liveframe/blob/main/src/__tests__/host-intent.test.ts), `authorize_throw_fails_closed` |
| Serialising calls per placement and scope | The pipeline holds no state between calls. With a store's `putStateIf`, concurrent `setState` calls keep each other's keys. | Serialise `renderPlacement` and `handleIntent` per placement and scope. | [`host-intent.test.ts`](https://github.com/ashiqrniloy/liveframe/blob/main/src/__tests__/host-intent.test.ts), `concurrent_set_state_on_two_keys_keeps_both`; not checked by the library: [LF-28](https://github.com/ashiqrniloy/liveframe/blob/main/plans/requests/synapta-0.4.0-requests.md#lf-28--feature--served-cannot-be-persisted-so-a-multi-replica-host-has-no-session) |
| Agent drafts under `liveframe mcp` | Inline drafts are size-bounded before transpiling. Without `config.runner`, drafts run with the process's permissions, and the server warns once on stderr. | Give an agent you do not trust an isolated `config.runner`. | [`authoring.test.ts`](https://github.com/ashiqrniloy/liveframe/blob/main/src/__tests__/authoring.test.ts), `oversized_inline_draft_is_refused_before_transpile`; [`cli-mcp.test.ts`](https://github.com/ashiqrniloy/liveframe/blob/main/src/__tests__/cli-mcp.test.ts), `default_runner_warns_on_stderr` |
| Inline styles and CSP | Widget code cannot set colours or raw CSS. Layout is drawn as inline `style` attributes from catalog and recipe values. | Allow `style-src-attr 'unsafe-inline'` in your CSP, and authorise the stylesheets with a URL or nonce. See [styling](styling.md). | [`react-surface.test.tsx`](https://github.com/ashiqrniloy/liveframe/blob/main/src/__tests__/react-surface.test.tsx), `surface_renders_slot_classes_styles_and_scope` |
