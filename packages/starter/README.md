# @arnilo/liveframe-starter

A starting point for a [Liveframe](https://github.com/ashiqrniloy/liveframe) host: a reference catalog, React implementations, themes and a design system that pass every conformance suite. Copy it or extend it; it is not part of the core contract.

> Work in progress for 0.3.0. The content lands in plan 031 Task 6; this package currently exports nothing.

Requires Bun ≥ 1.4.2 and `@arnilo/liveframe` `~0.3.0`.
